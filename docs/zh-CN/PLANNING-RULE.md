# 规划规则协议 — v0.3

TST Chain v0.3 将规划要求表达为可版本化、机器可读、可验证的规则。

`PlanningRule` 负责说明**检查什么**，`RuleEngine` 负责说明**如何对某组输入进行核验**。可信链记录规则版本、输入摘要、引擎身份和结果，但不替代 GIS、BIM、TIM，也不替代行政裁量。

### 支持的规则表达
- 数值阈值与数值范围
- 枚举条件
- 布尔条件
- 空间谓词

协议中的十进制数采用规范字符串，例如 `"2.5"`、`"45"`；不使用 JSON 二进制浮点数。

### 规则例外
例外必须成为独立对象，拥有签发主体、生效期限和依据，不允许静默修改原规则。`review_required` 会产生 `review` 结果，而不是由算法自动批准或驳回。

### 外部引擎接口
`TST-RULE-ENGINE/0.3` 声明引擎能力。GIS / BIM / TIM 实现负责链下几何或模型计算，并返回带证据引用的观测结果。

### 核验结果语义
`pass`、`fail`、`review`、`not_applicable`、`error` 都只是机器核验状态。生产系统中的法定或行政决定必须作为独立、可签名的业务事件处理。
